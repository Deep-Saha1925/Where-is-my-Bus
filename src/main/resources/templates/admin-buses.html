How to prepare the file
Any Excel format works — .xlsx, .xls or .xlsm
  1. Row 1 is the header — use these exact column names.
  2. stop_order — 1, 2, 3... in the order a bus passes each stop
  3. stop_name, latitude, longitude — per stop
  4. distance_km — cumulative distance from the first stop
  5. slack_min — scheduled halt time at that stop, or 0
  6. Give the route a short code (e.g. APD_FLK) and a readable name when you upload — this adds a new route, it won't overwrite any existing one.

Bulk-update bus rosters
Set bus numbers for many routes in one file, instead of editing them one by one
  1. Row 1 is the header — use these exact column names.
  2. route_code — must match an existing route's code exactly (see the Routes tab)
  3. bus_number — one row per bus; add multiple rows with the same route_code to list several buses on one route
  4. For each route_code in the file, its bus list is fully replaced with what's in the file. Routes not mentioned in the file are left untouched.

Add / update timetable
Add one departure at a time below, or upload a file for many at once
Or upload many at once
  1. Row 1 is the header — use these exact column names.
  2. route_code — must match an existing route's code exactly (see the Routes tab)
  3. route_name — just for readability in the sheet; the name shown to passengers still comes from the Routes tab
  4. departure_time — one row per departure; repeat route_code across rows for multiple timings
  5. Every entry is assumed to run daily — there's no day-of-week or live status here, just a plain scheduled time.
  6. For each route_code in the file, its timetable is fully replaced with what's in the file. Routes not mentioned in the file are left untouched.
